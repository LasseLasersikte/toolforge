# ToolForge

A browser-based utility toolkit (10 client-side tools), a pricing page, and a blog with a
content-automation pipeline.

## Build

```
npm run build          # tools + blog + sitemap
npm run content:new    # generate next blog post, then rebuild blog + sitemap
npm run serve          # serve public/ locally on :4173
```

`public/tools/*.html` is generated by `scripts/build-tools.js` — edit the `TOOLS` array there,
not the generated HTML directly. Same for `public/blog/*` via `scripts/build-blog.js` and
`content/posts/*.json`.

`scripts/build-sitemap.js` reads `SITE_URL` from the environment (defaults to
`https://toolforge.example.com`) — set it to the real production domain before building for
deploy, e.g. `SITE_URL=https://toolforge.app npm run build`.

## Payments

Checkout on `/pricing.html` is currently a placeholder `alert()`. To accept real payments:

1. Create a Stripe Payment Link (or Checkout Session) per plan.
2. In `public/pricing.html`, replace the `startCheckout()` function with a redirect to the
   relevant Payment Link URL (or a fetch call to your own Checkout Session endpoint).

No ad network is wired into the `.ad-slot` placeholders — they're static reserved space.
